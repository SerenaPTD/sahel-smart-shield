6. Points critiques à ne pas rater
Isolation galvanique obligatoire Les circuits 230V AC (charges, ventilateur) ne doivent jamais partager la même masse que les circuits 24V DC de commande. Utiliser des contacteurs avec séparation galvanique certifiée. Ne jamais relier le neutre 230V à la masse 24V DC.
Câbles blindés pour les signaux 4-20mA Dans un environnement industriel avec des perturbations électromagnétiques, les signaux 4-20mA doivent être acheminés dans des câbles blindés avec le blindage relié à la terre côté armoire uniquement (pas côté capteur).
Anti-rebond secteur AC — 2 secondes La détection de coupure secteur intègre un anti-rebond de 2 secondes (TON_SECTEUR dans sss_main_pro.st) pour éviter les fausses alarmes dues aux micro-coupures normales du réseau.
Temporisations avant délestage La ventilation s'active avec un délai de 5 secondes, le délestage avec un délai de 30 secondes. Ces délais sont configurables dans sss_config_pro.st. Ils évitent les actions intempestives sur des pics de température passagers.
Module LOGO! CMR2040 — Extension Ethernet optionnelle Pour la supervision Modbus TCP avec le Raspberry Pi, ajouter le module CMR2040 directement sur le LOGO! 12/24RC. Il se configure via navigateur web sur son adresse IP locale. Sans ce module, la supervision reste possible via le port RS232 du LOGO!.
